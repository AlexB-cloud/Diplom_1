# Stellar Burgers Unit Tests

##  Описание
Юнит-тесты для проверки функционала сервиса Stellar Burgers:
- `Bun` - модель булочки
- `Burger` - модель бургера
- `Ingredient` - модель ингредиента
- `IngredientType` - перечисление типов ингредиентов

Разработаны в рамках дипломной работы.

##  Технологии
| Технология | Версия |
|------------|--------|
| Java | 11 |
| JUnit | 4.13.2 |
| Mockito | 3.12.4 |
| Maven | 3.8.1 |
| JaCoCo | 0.8.12 |

##  Запуск тестов

### Стандартный запуск всех тестов
```bash
mvn clean test
```
### Генерация отчета о покрытии кода
```bash
mvn jacoco:report
```
